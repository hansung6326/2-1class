#### 추상화 기초

* 추상화
  * 복잡한 문제를 해결하기 위한 방법
  * 불필요한 부분 제거/생략
  * 필요한 속성을 이용하여 단순화
* 프로그래밍 언어에서의 추상화
  * 데이터 추상화 -> record
  * 제어(알고리즘) 추상화 -> function

* 데이터 추상화

  * integer, char, string, real ... -> 하나의 새로운 data type

  * 예

    Student_number : integer

    Name : string

    Major : enumeration

  * record

* 제어 추상화

  * 절차를 단순화
  * 서브프로그램: 이름, 매개변수, 기능을 이용하여 단순화

#### 추상화 자료형

* Abstract Data Type
  * 프로그래머 정의 데이터 유형 + sub-program
  * class in C++, package in Ada = 추상 데이터 유형
* 정의
  * 사용자 정의 데이터 집합
  * 사용자 정의 데이터 연산
  * 캡슐화
* 추상화
  * 매우 복잡한 데이터: 외부 인터페이스 + 객체의 함수
  * 자세한 구현을 감춤
  * Ex: 라이브러리 함수 사용
* C, Pascal
  * 데이터와 제어의 단순화
  * ADT아님 <- 캡슐화 지원 안됨
* ADT의 개념
  * 정보 은닉
    * 추상 데이터 유형의 내부 데이터나 구현의 상세한 것을 감춤
    * Ex: 서브프로그램의 지역 변수
  * 데이터 캡슐화
    * ADT의 내부 데이터 접근 : 미리 정의된 함수만을 이용
    * 소스 코드 독립성 -> 소프트웨어 모듈화
* Why ADT?
  * 프로그램의 수정을 쉽게
  * 재사용과 보안
* 예: stack, queue
  * 데이터 저장을 위한 변수:  array
  * 내부 데이터를 위한 접근 방법: push(), pop()

#### C++에서의 객체 지향 개념

  * 객체에 대한 명세

* 소멸자: 객체 소멸 시, 자동으로 호출됨

  * 속성을 공유하는 클래스 간의 관계
