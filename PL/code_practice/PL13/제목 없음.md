#### 힙 기반 기억 장소 관리

  * allocation, recovery, compaction, reuse 등을 위한 기술이 필요
  * 기억 장소 수집 기술도 필요

* 힙의 필요성

  * 프로그램 실행 중 아무 때나 메모리 할당/해제 할 수 있음
  * 프로그램의 어떤 위치에서나 데이터 구조 생성, 삭제 할 수 있음

* 힙 메모리 관리

  * 고정 크기 기억 장소 할당
    * 간단
    * no compaction
  * 가변 크기 기억 장소 할당

* 고정 크기 기억 장소 할당

  * Heap

    * K블록
    * Block: N word size
    * Heap 크기 = N x K

  * 사용 가능 블록 리스트 유지

  * 할당: 첫 번째 블록 할당 -> 사용 가능 리스트에서 삭제

  * 해제: 사용 가능 리스트의 처음에 연결

  * 복구

    * 프로그래머 or 시스템
    * free(), delete
    * garbage, dangling reference의 위험성

  * 참조 계수

    * 기억 장소에 대한 포인터 개수: 허상 참조를 막음
    * 추가의 공간이 필요함

  * 쓰레기 수집

    * 사용 가능 블록이 없을 때, 프로그램의 실행을 중단하고 쓰레기 수집을 시작

    * 2단계

      마크: garbage(ON), 사용 중인 블록(OFF)

      청소: "ON"으로 표시된 블록을 사용 가능 블록 리스트에 추가
